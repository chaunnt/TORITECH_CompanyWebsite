Tài liệu kỹ thuật

Dành cho CTO, kỹ sư tích hợp và đội vận hành: kiến trúc, cách kết nối MCP Server, API đặt lịch, sự kiện VMS và trạng thái dịch vụ.

1. Kiến trúc hệ thống

Nền tảng gồm ba khối chạy độc lập, giao tiếp qua API và hàng đợi sự kiện:

KhốiThành phầnTriển khai
AI Vision & VMSBộ thu luồng RTSP/ONVIF, dịch vụ suy luận AI, lưu trữ video/sự kiện, bản đồ giám sátEdge tại cơ sở + trung tâm (Cloud VN / On-Premise)
Đặt lịch & Điều phốiCore (bộ đếm slot, sổ sự kiện ký số, đối soát), Edge node tại đối tác, dịch vụ thông báoCore tại Việt Nam; Edge trên hạ tầng đối tác
MCP & AI AgentMCP Server theo lĩnh vực, cổng xác thực OAuth/API key, Audit Log, hàng đợi phê duyệtSaaS hoặc Private Cloud của khách hàng

2. Kết nối MCP Server

MCP Server của TORITECH dùng giao thức Model Context Protocol qua HTTP (Streamable HTTP). Các trợ lý hỗ trợ MCP như Claude, ChatGPT, Gemini, Copilot có thể thêm connector bằng URL do TORITECH cấp.

  1. Nhận URL MCP và API key (hoặc thực hiện đăng nhập OAuth) sau khi kích hoạt dịch vụ.
  2. Trong trợ lý AI, mở phần cài đặt connector / tích hợp, thêm connector tuỳ chỉnh với URL được cấp.
  3. Khai báo key theo hướng dẫn kèm theo; không chia sẻ key qua kênh công khai.
  4. Thử một lệnh chỉ đọc, ví dụ: “Liệt kê các công cụ có sẵn”.
Key là thông tin bí mật của từng khách hàng. Khi nghi bị lộ, liên hệ TORITECH để thu hồi key và xoá thông tin đã lưu.

Ví dụ cấu hình (giá trị giả lập)

{
  "mcpServers": {
    "toritech-dvc": {
      "url": "https://mcp.example.vn/dvc",
      "headers": { "Authorization": "Bearer ••••••••••••" }
    }
  }
}

3. API đặt lịch (tóm tắt)

LuồngMô tả
Lấy giờ trốngĐọc snapshot khung giờ theo cơ sở/ngày (cache 30–60 giây)
Giữ chỗMột lệnh giữ chỗ nhẹ trên bộ đếm slot chung; trả về mã đặt lịch
Xác nhận / Huỷ / Đổi giờGhi sự kiện vào outbox, đẩy về Core theo lô

Tài liệu OpenAPI đầy đủ và môi trường sandbox được cấp cho đối tác sau khi ký thỏa thuận tích hợp.

4. Sự kiện VMS

Sự kiện AI (phương tiện, vi phạm vùng, camera mất tín hiệu…) được đẩy qua Webhook/REST với mã sự kiện, thời gian, camera, ảnh trích đã làm mờ theo cấu hình. Ảnh chụp màn hình và log minh hoạ trong tài liệu luôn dùng dữ liệu giả lập.

5. Trạng thái dịch vụ

Khách hàng doanh nghiệp được cấp trang trạng thái và báo cáo SLA định kỳ theo hợp đồng. Thông báo sự cố và bảo trì có kế hoạch được gửi qua email/Zalo đã đăng ký. Trang trạng thái công khai đang được chuẩn bị.

6. Câu hỏi thường gặp

AI Agent có thể tự ý sửa, xoá dữ liệu ERP/kế toán không?

Mặc định MCP Server chỉ cấp quyền đọc. Các lệnh ghi, sửa, xoá hoặc gửi ra ngoài phải được khai báo trong phạm vi quyền và đi qua bước phê duyệt của người có thẩm quyền (Human-in-the-loop). Mọi lệnh đều có Audit Log.

Có tận dụng được camera và đầu ghi đang có không?

Có. Nền tảng VMS kết nối camera IP và đầu ghi NVR sẵn có qua chuẩn ONVIF/RTSP, không yêu cầu thay thiết bị nếu thiết bị đáp ứng yêu cầu tối thiểu về luồng video.

Thời gian triển khai thường mất bao lâu?

Một đợt thí điểm điển hình kéo dài khoảng 3 tháng: khảo sát 1–2 tuần, kết nối và cấu hình 3–5 tuần, vận hành thử và đo kết quả trong thời gian còn lại. Tiến độ cụ thể phụ thuộc hiện trạng hạ tầng.
